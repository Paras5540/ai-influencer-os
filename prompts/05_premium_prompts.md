# 05 — Premium (glamour) prompt library

These are tasteful-by-default. They are what actually sells subscriptions: **teasing, not explicit.**
Lingerie / boudoir / implied — yes. Explicit acts or genitalia — no. Fanvue removes them and repeated
strikes kill the account.

Rule that keeps the account alive: **public tier = fully clothed. Premium tier = lingerie max.**

---

## A. Premium teaser still (Fanvue cover / PPV preview)
```
Using the reference image as the exact identity of the woman, keep her face 100% unchanged.
SCENE: {location}, shot at {time_of_day}
OUTFIT: {lingerie_set | oversized shirt half-buttoned | silk slip}
POSE: {pose}, relaxed, looking at camera
CAMERA: 50mm portrait, vertical 4:5, waist-up
LIGHT: {soft window light | warm lamp glow | single key light from the side}
MOOD: intimate, cinematic, film grain, warm skin tones
Photorealistic, visible skin texture and pores, natural body proportions (no exaggeration),
no nudity, no explicit content, no plastic skin, no airbrushing.
```

## B. "Getting ready" series (highest converting free-post teaser)
```
same woman, in front of a mirror in a hotel room, silk robe over a black lace set,
holding a brush, hair slightly messy, warm lamp light, candid mid-motion, vertical 9:16
```

## C. Bedroom / boudoir set
```
same woman, on a bed with white sheets, wearing {cream lace bralette | oversized tee},
lying on her side, propped on one elbow, soft morning light through curtains,
shallow depth of field, natural skin, implied only, no nudity
```

## D. Shower / wet look (borderline — Fanvue ok, never Instagram)
```
same woman, wet hair slicked back, white towel wrapped, steam in the air, bathroom tiles,
warm backlight, water droplets on the shoulder, no nudity
```

## Negative prompt (always append)
```
nudity, explicit, sexual act, genitalia, minor, childlike, school uniform, plastic skin,
airbrushed, deformed hands, extra fingers, watermark, text, logo
```

---

## Public-tier translation of the same shoot (for the funnel)
Take the premium shoot and change only outfit + crop:
`same face, same room, now wearing an oversized shirt buttoned up, waist-up, smiling` ->
Instagram-safe. This is how one shoot produces 2 tiers with 1 generation pass.
